# subaru_brz_ZA1JF00A

2015年前期D型の JDM BRZ MT、ROM ZA1JF00A 用の EcuFlash 定義ファイルです。

Author: S.S

使用は自己責任です。この定義の使用によって生じた損害、傷害、故障について、作者は責任を負いません。

`ZA1JF00A.xml` を、EcuFlash をインストールしたフォルダの中の `rommetadata\subaru\BRZ\2015\` へコピーしてください。64ビット Windows では、多くの場合は以下です。

`C:\Program Files (x86)\OpenECU\EcuFlash\rommetadata\subaru\BRZ\2015\`

コピーしたあと、EcuFlash を再起動してください。

調整の前に `ZA1JF00A-definition-list.ja.md` または `ZA1JF00A-definition-list.en.md` を読んでください。

**Warning:** ROM を変更する前に、必ずバックアップを取ってください。
